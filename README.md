## 📌 About the Project

**React Learning Hub** is a practical learning repository focused on mastering React through hands-on coding, examples, exercises, and mini-projects.

The goal is to build a strong foundation in modern frontend development, from basic JSX and components to hooks, API integration, routing, and reusable UI architecture.

## 🎯 Learning Objectives

- Understand React fundamentals and JSX.
- Build reusable functional components.
- Learn props, state, and event handling.
- Master React Hooks.
- Render lists and handle conditional UI.
- Fetch and display data from APIs.
- Create responsive and interactive interfaces.
- Develop real-world React mini-projects.

## 🧠 React Concepts

| Concept               | Description                                     |
| --------------------- | ----------------------------------------------- |
| JSX                   | Write HTML-like syntax inside JavaScript        |
| Components            | Build reusable UI elements                      |
| Props                 | Pass data between components                    |
| `useState`            | Manage component state                          |
| `useEffect`           | Handle side effects                             |
| Event Handling        | Respond to user interactions                    |
| Conditional Rendering | Display UI based on conditions                  |
| Lists & Keys          | Render collections of data                      |
| `useRef`              | Reference DOM elements and store mutable values |
| `useMemo`             | Memoize calculated values                       |
| `useCallback`         | Memoize function references                     |
| API Integration       | Fetch and display external data                 |
| React Router          | Navigate between application pages              |

## 🚀 Getting Started

### Prerequisites

Install the following tools before starting:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- [Git](https://git-scm.com/)
- A code editor such as [Visual Studio Code](https://code.visualstudio.com/)

### 1. Clone the Repository

```bash
git clone https://github.com/Saravanan-mc/React_Learning.git
```

### 2. Navigate to the Project

```bash
cd React_Learning
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal, usually:

```text
http://localhost:5173
```
